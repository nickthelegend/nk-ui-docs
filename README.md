# 📖 NickTheLegend UI — Documentation

The premium documentation site for the **NickTheLegend UI** React Native component library, built with Next.js 15 App Router and Tailwind CSS v4.

## 🚀 Overview

This site serves as the central hub for developers to explore the installation, theming, and component API for the `nickthelegend-ui` CLI. It features a stunning dark-mode first design matching the exact "Amber-Orange" Airbills aesthetic of the library.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript

## 💻 Running Locally

To run the documentation site locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```
Navigate to `http://localhost:3000` to view the site.

## 🎨 Contributing
The documentation uses a specialized `globals.css` file to enforce the dark fintech branding. When adding new component pages under `app/docs/`, ensure you map the React Native visual equivalents using standard Tailwind utility classes to match the core `nickthelegend-ui` theme tokens.
